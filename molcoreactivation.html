Official Quanalv Activation Policy

Molcore 1.0 Standard registers 1 workstation. Molcore Family Pack 1.0.0 registers up to 5 personal household PCs. Molcore Business Edition master keys register unlimited computers within the licensed organization.

DEPLOYMENT & REGISTRATION METHODS

Online & Air-Gapped Activation Paths

Standard Connected Setup

Direct Online Activation

Recommended for home workstations and internet-connected office systems completing first-boot setup.

  • Instant one-time cryptographic key verification
  • No recurring background license heartbeats
  • Supports Standard, Family Pack, and Business keys
  • Automatic local entitlement receipt storage

Enterprise & Secure Enclaves

Offline Certificate Activation

Designed for laboratory hardware, secure facilities, and bulk-imaged workstations operating without internet access.

  • Generates signed local QMCERT-1.0 certificate file
  • Binds cleanly to workstation hardware ID
  • Compatible with automated PXE & disk imaging
  • Zero external network dependency after imaging

SYSTEM ADMINISTRATION

Command-Line Activation Utility

1. Check Entitlement Status

Inspect current OS edition, local license receipt state, and machine hardware fingerprint.

# qm-activate --status

2. Register Product Key

Apply a Standard, Family Pack, or Organizational Master Key directly from a terminal session.

# qm-activate --key QMBZ-XXXX-XXXX

3. Import Offline Token

Install a signed certificate file generated on this portal onto an air-gapped workstation.

# qm-activate --cert /root/qm.cert
