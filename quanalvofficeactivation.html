WORKSTATION PROVISIONING

Command-Line & Air-Gapped Activation

Administrators and workstation users can register Quanalv Office 1.0 directly from the Molcore terminal without launching a graphical wizard.

# 1. Activate Quanalv Office online using your 25-character product key
sudo qo-activate --key QO10-8492A-7710C-3940E-9124B

# 2. Generate a local hardware fingerprint for an air-gapped computer
qo-activate --hwid

# 3. Apply the offline activation token generated on this portal
sudo qo-activate --apply-token QOCERT-1.0-8492A-9A4F22C8-PERPETUAL

# 4. Inspect current license channel and genuine status
qo-activate --status
